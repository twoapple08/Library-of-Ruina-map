  → 방에서 다음 층 조각 F = 다음 층 전경. 그 층 전경으로 전환하면 다음 층 조각 회수 (마그마크림 제외).
  이전 층 조각은 계속 가지고 있다가 F = 이전 층 지정사서 방
- 로비: 이전 층 없음. 방(전환 전)은 철조각만, 홀로 가면 금조각도 줌 → 홀에서 금조각 F = 역사의 층
- BSL 개조판을 저장소에 올려도 됨. 모드화는 이번 라운드 뒤 (기초 구성: `docs/mod/기초구성.md`)
