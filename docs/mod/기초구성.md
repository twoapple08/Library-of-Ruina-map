# 모드 기초 구성 (사용자 지시, 2026-10-12)

> 모드화는 사용자 지시 후 진행 (HANDOFF 4-1). 이 문서는 사용자가 정한 기초 구성과 답변을 그대로 정리한 것.
> 로더: Fabric (26.3, 테스터가 이미 씀). 빌드는 GitHub CI에서만 가능 (작업 환경에서 Fabric 저장소·Mojang 접속 막힘).

## 모드화를 하는 이유 (사용자 원문과 답변, 2026-10-12)

사용자:
```
모드화를 제안한 이유가 모드화를 하면 블록의 크기 같은거나 오브젝트나 묘사를 맘대로 가능한 수준이니까
그냥 원화를 빼다박은 수준의 퀄리티가 되지않을까 싶어서 얘기 한거야
```
→ **목표: 원화를 빼다 박은 수준의 퀄리티.** (앞서 Chisel 계열 모드를 물은 것도 같은 이유: 묘사 디테일 상승)

답변 요지 (Claude):
- 방향은 맞음. 모드로 가면 표현의 한계가 거의 없어지고, 품질을 정하는 것은 "엔진"이 아니라 모델·텍스처를 얼마나 잘 만드느냐가 됨
- 모드로 가능해지는 것: 블록 격자와 상관없는 **자유로운 모양**(곡선 가지, 얇은 난간, 시계 바늘 — 삼각형 면), **크기 자유**
  (아주 작은 장식 ~ 수백 칸 한 덩어리), **큰 텍스처**(16×16 제한 없음, 원화 질감), **움직임**(톱니 회전, 진자, 종이 흩날림),
  **하늘·먼 배경을 그림으로**
- 원화를 빼다 박는 가장 유력한 방법 = **원화 투영**: 층마다 도착 자리가 원화와 같은 구도 → 대략적인 3D 형체를 만들고 원화를 그 시점에서
  형체 위에 비춰 입힘 → 도착 자리에서는 원화와 거의 똑같이, 걸어 다니면 입체. 시점에서 멀어질수록 어긋나니 가까운 곳은 직접 만든 모델로 보완
- 걸리는 점: 충돌·조명은 여전히 블록 단위 (걷는 바닥은 블록, 보이는 모습은 모델로 덮음) / BSL과 호환 확인 필요 / GTX1050ti 성능 /
  게임 원화를 텍스처로 넣어 배포하는 범위는 생각해 둘 것 / 모드 빌드는 GitHub CI에서만 (Fabric client gametest 로 CI 스크린샷 비교 가능한지 확인)
- 추천 진행: 데이터팩 라운드(소리·층 이동·버그·BSL) 마무리 → 층 하나(총류 추천) 원화 투영·자유 모델로 시험 → CI 스크린샷 비교 → 나머지 층·외부

사용자 결정: 1번(데이터팩 라운드)만 먼저 하고 멈춤 → 모드 기초 구성 전달 (아래).
이후 (3차 테스트 뒤): **다음 테스트가 성공하면 모드화로 넘어가고, 건축물 묘사와 오브젝트 움직임까지 전부 구현.**

## 사용자 원문

```
모드 기초 구성
일단 현재 블록이 아닌 아이템 아이콘(예: 철조각 이미지)같은거의 텍스쳐는 그냥 해당 아이템의 이름으로 처리

상호작용(우클릭으로 변경) 및 텔포를 위한 아이템.
1. 초대장
일반 야생에서 상호작용시 도서관 건물이 있는차원으로 이동(도서관 전경이 있는 차원에서 사용시 차원 이동전 위치로 복귀)
2. 방전환
특정 차원(언어의 층, 총류의 층)에서 사용시 지정사서 방과 전경을 왔다갔다 할 수 있는 아이템
3.말쿠트, 예소드, 호드, 네짜흐, 티페리트, 게부라, 헤세드, 비나, 호크마, 케테르
각각 해당층의 차원으로 텔포 시켜주는 템(전경으로 텔포 지정사서방에서도 사용가능)

+추가 사항 모드에서 자동 템지급은 빼 따로 크리에티브 탬창에서 가져오는 방식으로 진행 할거니까
```

## 질문에 대한 답 (정리)
| 질문 | 답 |
|---|---|
| 이번 라운드(데이터팩)도 우클릭으로? | 아니오. **모드화 전까지는 F 통일** (황금사과 같은 음식이 있어서) |
| 방전환은 언어·총류에서만? | 아니오, 예시였음 ("등"을 빠뜨림) → **모든 층**(과 로비 방↔홀)에서 지정사서 방 ↔ 전경 |
| 아이템 얻는 법 | 제작법 없음. **크리에이티브 모드 아이템 창(모드 탭)에서 꺼냄**. 자동 지급 없음 |
| 초대장을 도서관 다른 공간(로비·층)에서 쓰면 | **야생으로 돌아가기** (초대장 쓰기 전 자리. 기록이 없으면 월드 스폰) |
| 로비 가는 길 | 지금처럼 **정문 홈으로 걸어 들어가기** |
| 아이콘 | **아이템 이름 글자를 써 넣은 단순한 아이콘** 자동 생성 (추천안) |
| 자연과학의 층 색 전환 | 자연과학 차원에서 **티페리트를 왼손으로 들기(F)** 하면 돔 색이 바뀜 |
| 기존 조각 아이템 (철조각~마법이 부여된 황금사과, 마그마크림) | **없애지 말고 기능만 없앰**. 기능은 세피라 아이템으로 |

## 아이템 (정리)
| 아이템 | 사용 | 동작 |
|---|---|---|
| 초대장 | 우클릭 | 야생(도서관 밖) → 외부(도서관 전경) 차원, 쓰기 전 자리 기록 / 도서관 안 어디서든 → 기록한 자리로 |
| 방전환 | 우클릭 | 로비·각 층: 지정사서 방 ↔ 전경 (같은 차원 안) |
| 말쿠트·예소드·호드·네짜흐·티페리트·게부라·헤세드·비나·호크마·케테르 | 우클릭 | 그 층(역사·기술과학·문학·예술·자연과학·언어·사회과학·철학·종교·총류) 전경으로 TP. 지정사서 방에서도 사용 가능 |
| 티페리트 | 자연과학 차원에서 F | 돔 색 전환 (금빛 ↔ 청록) |
| 기존 조각 11종 + 마그마크림 | — | 장식용 아이템 (기능 없음) |

## 다음 단계 (모드 시험 제작, HANDOFF 4절)
- 보조 모드 1단계: 아이템(위 표)·소리·리소스. 맵은 지금처럼 빌드 코드로 만든 월드 → 나중에 모드가 차원·구조물까지
- 원화 투영(도착 시점에서 원화를 형체에 비춰 입힘)·자유 모델로 층 하나 시험 (총류의 층 추천) → CI 스크린샷 비교

## 4차 테스트 뒤 결정 (2026-10-12) — 모드 요구사항에 추가
| 질문 | 답 |
|---|---|
| 남은 것을 데이터팩으로 한 번 더? | **모드에서 하자** (4차 = 통과) |
| 암흑 효과 규칙 | 맞음: 정문↔로비·층 사이 이동 = **암흑 1초 → 이동 → 도착지에서 1초 뒤 풀림**. 방↔전경 전환은 번쩍임만 바로. **야간투시 효과 전부 제거** |
| 티페리트 색 전환 | 제자리에서 주변(돔)이 바뀜. 금빛 ↔ 청록 두 벌, **원화 색에 맞출 것** |
| 총류 지정사서 방 | **높이 트인 공간** (밝게) |
| 철학 은하수 | 하늘에 그림(텍스처)으로 — 좋음 |
| 진행 순서 | 맞음: ① 기본 틀 → ② 층 하나 시험(총류) → ③ 나머지 층·외부 묘사와 움직임 |

모드 ① 기본 틀 체크리스트:
- Fabric 26.3 모드 (CI에서 빌드·검사, 작업 환경에서는 Fabric maven 접속 안 됨)
- 아이템: 초대장, 방전환, 세피라 10종(말쿠트·예소드·호드·네짜흐·티페리트·게부라·헤세드·비나·호크마·케테르), 기존 조각 11종 + 마그마크림(기능 없음)
  — 우클릭, **크리에이티브 모드 탭에서만** (자동 지급 없음), 아이콘 = 이름 글자 자동 생성
- 초대장: 야생 → 외부(자리 기록) / 도서관 안 어디서든 → 기록한 자리 (없으면 월드 스폰)
- 방전환: 로비 방↔홀, 각 층 지정사서 방↔전경 (번쩍임, 바로)
- 세피라: 그 층 전경으로 (암흑 1초 규칙), 방에서도 사용 가능. 티페리트는 자연과학 차원에서 F = 돔 색 전환(제자리)
- 정문 홈 걸어 들어가기 → 로비 (지금처럼), 로비 남쪽 문 → 외부
- 소리(`resourcepack/` 의 로비 홀 음악·전환 소리)를 모드 리소스로, 리스폰 시 스폰 자리, 야간투시 없음
- 월드(차원·구조물)는 처음엔 지금 빌드 코드가 만든 월드 그대로 → 나중에 모드가 차원·구조물까지

## 모드화 ① 진행 중 사용자 확인 (2026-10-12)
- **모드 아이템은 초대장·방전환·세피라 10종(12개)만.** 예전 조각(철조각~마법이 부여된 황금사과, 마그마크림)은 바닐라 아이템 그대로 두고 기능만 없앰 (모드 아이템으로 만들지 않음)
- 모드 파일 크기·모드 블록 수 제한 없음, **오직 높은 퀄리티** (단, GTX1050ti fps 고려: 가까이 정밀, 멀리 단순)
- **이펙트도 모드 전용으로 퀄리티 있게** (이동 암전·방전환 번쩍임 등), 최적화 필수
- 모드 업데이트 시 이미 방문한 월드의 도서관 건축물도 새 버전으로 교체
- 초대장: 야생에서 우클릭하면 도서관 맵으로 이동 (재확인)
