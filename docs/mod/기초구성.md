# 모드 기초 구성 (사용자 지시, 2026-10-12)

> 모드화는 사용자 지시 후 진행 (HANDOFF 4-1). 이 문서는 사용자가 정한 기초 구성과 답변을 그대로 정리한 것.
> 로더: Fabric (26.3, 테스터가 이미 씀). 빌드는 GitHub CI에서만 가능 (작업 환경에서 Fabric 저장소·Mojang 접속 막힘).

## 사용자 원문

```
모드 기초 구성
일단 현재 블록이 아닌 아이템 아이콘(예: 철조각 이미지)같은거의 텍스쳐는 그냥 해당 아이템의 이름으로 처리

상호작용(우클릭으로 변경) 및 텔포를 위한 아이템.
1. 초대장
일반 야생에서 상호작용시 도서관 건물이 있는차원으로 이동(도서관 전경이 있는 차원에서 사용시 차원 이동전 위치로 복귀)
2. 방전환
특정 차원(언어의 층, 총류의 층)에서 사용시 지정사서 방과 전경을 왔다갔다 할 수 있는 아이템
3.말쿠트, 예소드, 호드, 네짜흐, 티페리트, 게부라, 헤세드, 비나, 호크마, 케테르
각각 해당층의 차원으로 텔포 시켜주는 템(전경으로 텔포 지정사서방에서도 사용가능)

+추가 사항 모드에서 자동 템지급은 빼 따로 크리에티브 탬창에서 가져오는 방식으로 진행 할거니까
```

## 질문에 대한 답 (정리)
| 질문 | 답 |
|---|---|
| 이번 라운드(데이터팩)도 우클릭으로? | 아니오. **모드화 전까지는 F 통일** (황금사과 같은 음식이 있어서) |
| 방전환은 언어·총류에서만? | 아니오, 예시였음 ("등"을 빠뜨림) → **모든 층**(과 로비 방↔홀)에서 지정사서 방 ↔ 전경 |
| 아이템 얻는 법 | 제작법 없음. **크리에이티브 모드 아이템 창(모드 탭)에서 꺼냄**. 자동 지급 없음 |
| 초대장을 도서관 다른 공간(로비·층)에서 쓰면 | **야생으로 돌아가기** (초대장 쓰기 전 자리. 기록이 없으면 월드 스폰) |
| 로비 가는 길 | 지금처럼 **정문 홈으로 걸어 들어가기** |
| 아이콘 | **아이템 이름 글자를 써 넣은 단순한 아이콘** 자동 생성 (추천안) |
| 자연과학의 층 색 전환 | 자연과학 차원에서 **티페리트를 왼손으로 들기(F)** 하면 돔 색이 바뀜 |
| 기존 조각 아이템 (철조각~마법이 부여된 황금사과, 마그마크림) | **없애지 말고 기능만 없앰**. 기능은 세피라 아이템으로 |

## 아이템 (정리)
| 아이템 | 사용 | 동작 |
|---|---|---|
| 초대장 | 우클릭 | 야생(도서관 밖) → 외부(도서관 전경) 차원, 쓰기 전 자리 기록 / 도서관 안 어디서든 → 기록한 자리로 |
| 방전환 | 우클릭 | 로비·각 층: 지정사서 방 ↔ 전경 (같은 차원 안) |
| 말쿠트·예소드·호드·네짜흐·티페리트·게부라·헤세드·비나·호크마·케테르 | 우클릭 | 그 층(역사·기술과학·문학·예술·자연과학·언어·사회과학·철학·종교·총류) 전경으로 TP. 지정사서 방에서도 사용 가능 |
| 티페리트 | 자연과학 차원에서 F | 돔 색 전환 (금빛 ↔ 청록) |
| 기존 조각 11종 + 마그마크림 | — | 장식용 아이템 (기능 없음) |
